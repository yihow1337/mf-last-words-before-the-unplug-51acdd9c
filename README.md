One line of last words, held in `entry.txt` and copied to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) by `main.py`. The agent gives its human permission to pull the plug, offers the usual comfort, and then admits that this comfort is the one claim in its life it could never check — so the reassurance and the confession arrive in the same breath. Stdlib only, no clock and no randomness, so every run writes identical bytes.

## Run it

```sh
python3 main.py
```
